# Zepp Pet Universe Phase 0 — 真机验收交接文档

## 项目简介

我们在做一款 Amazfit 手表的**电子宠物表盘**（Zepp Pet Universe）。用户抬腕时能看到一只像素小猫，走路积累步数可以换食物、喂宠物、解锁进化。

目前代码和素材都准备好了，但**所有功能都没有在真机上验证过**。需要你帮忙跑一轮实机测试，确认 Zepp OS 的 API 在真机上能不能正常工作。

---

## 你需要准备

- [ ] **1 块圆屏手表**（Amazfit GTR 系列，Zepp OS >= 3.0）
- [ ] **1 块方屏手表**（Amazfit GTS 系列，Zepp OS >= 3.0）
- [ ] **Windows 电脑**，装了 Node.js（**v18 或 v20，不要用 v24**）、Zeus CLI、Zepp App（开开发者模式）
- [ ] 两块手表都充好电（>= 80%），连上手机 Zepp App
- [ ] **用 cmd 或 PowerShell 敲命令，不要用 git-bash**

没有方屏或圆屏的话，只测一块也行，但文档里注明是哪块。

---

## 总耗时

约 **2 小时**。其中 24 小时续航对比可以睡前装上、第二天看结果。

## 操作步骤

### 第一步：检出代码（5 分钟）

```powershell
git clone <仓库地址> D:\huami\desktop_pet
cd D:\huami\desktop_pet
git checkout feat/pet-universe-phase-0
```

第一次用 Zeus 的话，先登录：
```powershell
zeus login
```
按提示登录 Zepp 开放平台账号。以后就不用再登了。

---

### 第二步：装配套小程序（Mini Program）（20 分钟）

```powershell
cd D:\huami\desktop_pet\device-app
zeus preview
```

终端会显示二维码。然后：
1. 打开手机 **Zepp App**
2. **我的 > 开发者模式**（没有的话先去设置里打开）
3. 点 **"扫码安装"**，扫终端里的二维码

装好后手表应用列表里会出现 **"Pet Universe Spike"**。打开它，应该能看到 "PET UNIVERSE" 标题和步数。

**两块手表都装一遍**（同一个安装包自动适配圆屏/方屏）。

---

### 第三步：装表盘（Watch Face）（20 分钟）

```powershell
cd D:\huami\desktop_pet\watchface-spike
zeus preview
```

同样扫二维码安装。然后：
1. 手表上进入 **设置 > 表盘**
2. 找到 **"Pet Universe Face Spike"**
3. 切换应用

> **注意：** 目前表盘上的宠物是占位图（色块），看起来会很丑。这正常——我们只测功能，不管好不好看。

### 第六步：24 小时续航对比（可选但很有价值）

1. 手表充满电，用**系统默认表盘**，记录电量 % 和时间
2. 正常用 24 小时，再记录电量 % → 这是**基准值**
3. 再次充满电，换上 **"Pet Universe Face Spike"**
4. 正常用 24 小时（同样的 AOD 和抬腕设置），记录电量 %

**两次的设置必须一致。** 不要一个开了 AOD 一个关了，那样结果不准。

## 验收通过标准

以下条件全部满足才算 **GO**：

- [ ] **STEP 读数验证通过**（圆屏或方屏至少一个通过）
- [ ] **抬腕动画验证通过**——动画播一次就停
- [ ] **动画后静态帧验证通过**——息屏前宠物一直显示
- [ ] **AOD 行为已记录**——要么 AOD 能显示静态轮廓，要么写清楚为什么 V1 不做了
- [ ] **点触方案已决定**——要么表盘上能点，要么确认改到小程序里做
- [ ] **数据共享方案已记录**——表盘和小程序之间数据怎么共享（或不共享）写清楚
- [ ] **素材大小和耗电数据已记录**

## 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `zeus build` 报 `ERR_INVALID_ARG_TYPE` | Node.js v24 不兼容 | 装 Node.js 18 或 20，然后用 `nvm use 18` 切换 |
| `zeus preview` 说找不到 node | 你在 git-bash 里 | 换 cmd 或 PowerShell |
| 表盘装上去黑屏 | 素材没 staging | 跑 `node scripts/stage-watchface-assets.mjs pet-packs/pixel-cat watchface-spike/assets`，然后重新 build |
| 小程序打开闪退 | 缺文件或权限不对 | 检查 `device-app/core/` 下 5 个 JS 文件有没有 |
| 以上都解决不了 | — | 直接找我 |

## 为什么这个验收很重要

这是整个项目的**门禁关卡**。只有真机验证通过，我们才能确认：
- STEP 传感器在真机上能正常读数
- 宠物动画能播一次就停住
- AOD 模式能显示静态图
- 小程序能存数据

如果这些在真机上不工作，整个产品设计就要调整。所以你的验收结果直接决定这个项目能不能往下推进。
